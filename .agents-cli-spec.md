# bs-notes Agent Spec

## Objective

Create a local ADK prototype agent that accepts a YouTube link, extracts the video's available transcript/captions, and creates detailed structured notes that strictly adhere to the video/audio transcript.

## Scope

- Input: one YouTube URL.
- Output:
  - cleaned timestamped transcript file
  - structured detailed notes file
  - optional JSON metadata file
- Primary extraction path: YouTube subtitles/auto-captions via `yt-dlp`.
- The notes must be grounded only in the extracted transcript and must not add outside facts, commentary, scriptural expansion, or model reasoning.
- The notes must read as subject-study notes rather than rearranged transcript: remove filler and repetition, preserve the teacher's reasoning, and organize supported content into concepts, distinctions, examples, applications, Q&A, and revision points.

## Guardrails

- Do not use web search or external sources to enrich the notes.
- Do not add content that is not explicitly present in the transcript.
- If the transcript is noisy, mark uncertainty instead of guessing.
- If captions are unavailable, report that transcription could not be completed unless an audio transcription backend is added later.
- Preserve timestamps for traceability.
- Distinguish statements by the speaker, cited source/purport points, audience questions, and participant comments when the transcript makes that distinction available.
- Do not silently repair uncertain Sanskrit, names, verse numbers, or quotations. Flag the timestamp and preserve uncertainty.

## Prototype Choice

This is a local prototype project with no deployment, no CI/CD, and no cloud infrastructure.
