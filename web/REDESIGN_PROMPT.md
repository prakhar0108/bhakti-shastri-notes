# UI Redesign Prompt — "Gita Editorial" theme

A robust, copy-paste-ready prompt for redesigning the `web/` UI (Fumadocs 16 +
Next.js 16 + Tailwind v4 + React 19) into a Bhagavad Gita / Bhakti Shastri themed
reading experience. Paste the block below to a coding agent.

---

**Role & Goal**
You are a senior front-end designer-engineer. Redesign the UI of the **"Bhakti Shastri Notes"**
documentation site (folder: `web/`) into a warm, sacred, editorial reading experience themed
around the **Bhagavad Gita** and Gaudiya Vaishnava tradition — while preserving 100% of existing
functionality. This is a **visual/UX redesign only**; do not change data flow, routing, or the
notes pipeline.

---

**Hard constraints (do not break)**

- Stack is **Fumadocs UI `^16`** + **Next.js `16.3.3` (App Router)** + **React `19`** +
  **Tailwind CSS `v4`** (CSS-first config via `@import 'tailwindcss'` in `src/app/globals.css` —
  there is **no `tailwind.config.js`**; use `@theme` and CSS variables). Read
  `web/node_modules/next/dist/docs/` before touching Next APIs; this Next version has breaking changes.
- **Never edit `web/content/docs/*.mdx`** — those are build artifacts generated by
  `scripts/sync-notes.mjs` (runs on `predev`/`prebuild`). The source of truth is
  `../outputs/**/notes/*.md`.
- Keep all Fumadocs features working: **DocsLayout sidebar** (one entry per lecture, ordered by
  "Day N"), **`/api/search` full-text search**, **light/dark/system theme toggle** (`next-themes`),
  **Mermaid diagrams** (`src/components/mdx/mermaid.tsx`), and **KaTeX math** (`$$...$$`).
- Preserve rendering of **Devanagari/Sanskrit** (e.g. `कर्म-योग`) and inline-code transliteration —
  must stay crisp and legible in both themes.
- Do the theming through Fumadocs' supported extension points: swap/override the CSS preset in
  `globals.css`, customize `baseOptions()` in `src/lib/layout.shared.tsx`, and `DocsLayout`/`DocsPage`
  props. Don't fork Fumadocs internals.
- Keep TypeScript strict; run `npm run lint` clean. Verify with `npm run dev` and `npm run build`.

---

**Visual theme — "Gita Editorial"**

- **Mood:** reverent, calm, scholarly, timeless — like an illuminated scripture crossed with a
  modern documentation site. Print-editorial whitespace, not flashy.
- **Color palette (define as CSS variables / `@theme` tokens, light + dark):**
  - Primary / accent: **saffron–marigold** (`#E8963A` / deep `#C2410C`), evoking sannyasa cloth.
  - Secondary accent: **peacock teal/indigo** (`#1F6F78` / `#2E3A8C`) — Krishna's peacock feather.
  - Gold hairlines/dividers for headings and cards (`#B8860B` used sparingly).
  - Light theme base: warm ivory / palm-leaf parchment (`#FBF7EF`), ink text `#2A2320`.
  - Dark theme base: deep midnight indigo (`#14121C` / `#0E0D14`), warm off-white text `#EDE6D8`;
    accents stay saffron/gold but slightly desaturated for contrast.
  - Ensure **WCAG AA** contrast for body text, code, and links in both themes.
- **Typography:**
  - Headings: an elegant serif with editorial character (e.g. self-hosted **Cormorant Garamond**
    or **Marcellus** via `next/font`), giving a "sacred text" feel.
  - Body: a highly readable serif or humanist sans (e.g. **Source Serif 4** or **Inter**) at
    generous line-height (~1.7) and a comfortable measure (~68–72ch).
  - Devanagari: pair a proper Indic font (e.g. **Noto Serif Devanagari**) so Sanskrit doesn't fall
    back to a mismatched glyph set; wire it into `next/font` and the CSS font stack.
  - Use `next/font` for all fonts (no CDN `<link>`), expose as CSS variables in `layout.tsx`.

---

**Layout & components to restyle**

1. **Global nav (`baseOptions()`):** add a small **brand mark** (a subtle lotus / peacock-feather /
   flute glyph as inline SVG) beside the title "Bhakti Shastri Notes". Refined, monochrome-with-accent,
   works in both themes. Keep the search + theme toggle.
2. **Landing / `/docs` index (`content/docs/index.mdx` is generated — restyle via the `Cards`/`Card`
   MDX components and CSS, not by editing the mdx):** turn the lecture list into elegant cards with a
   "Day N" ribbon/badge, BG shloka range, and a subtle parchment texture or gold hairline border on
   hover. Add a short devotional hero header above the cards (via the docs page/layout, not by editing
   generated mdx) — a tasteful banner with the app name, a one-line Sanskrit epigraph (e.g. a Gita
   verse) with transliteration, and calm gradient.
3. **Sidebar:** warm parchment/indigo background, saffron active-item indicator, gold section
   dividers, "Day N" numbering visually emphasized.
4. **Doc page (`DocsPage`/`DocsBody`):** editorial reading column, drop-cap or accented first heading
   optional, styled blockquotes as "commentary" callouts with a left gold rule, and beautiful
   `<table>` styling (the notes use comparison tables heavily — e.g. "Four Paths Compared") with
   striped rows, rounded corners, and a peacock-teal header.
5. **Inline code / transliteration chips:** style inline `code` (used for Sanskrit terms like
   `निष्काम कर्म-योग`) as soft saffron-tinted "chips" so terms stand out as vocabulary, distinct from
   code blocks.
6. **Callouts:** map Fumadocs `Callout`/admonition styles to themed variants — e.g. "Source discipline"
   / "Caption caution" notes should look like scholarly footnote panels.
7. **Mermaid diagrams (`mermaid.tsx`):** pass a **custom Mermaid theme** matching the palette (saffron
   nodes, indigo edges, parchment/midnight backgrounds) that switches with light/dark, so the
   auto-generated "Argument Map" flowcharts look on-brand and readable.
8. **KaTeX:** ensure math color inherits body ink color in both themes.
9. **TOC / "On this page":** subtle, right-aligned, gold active marker.
10. **Footer (optional):** a small, tasteful line with a closing invocation and a "generated from
    lecture transcripts" note.

---

**Polish & quality**

- Responsive: mobile-first; sidebar collapses cleanly; hero and cards reflow to single column;
  tables scroll horizontally without breaking layout.
- Micro-interactions: gentle hover/focus transitions (150–200ms), visible focus rings for keyboard
  nav, `prefers-reduced-motion` respected.
- Accessibility: semantic landmarks, AA contrast, alt text for the brand SVG, sufficient tap targets.
- Performance: self-hosted fonts with `display: swap`, no layout shift, no heavy images (use
  SVG/CSS gradients/textures).
- Keep the diff scoped to: `src/app/globals.css`, `src/app/layout.tsx`, `src/lib/layout.shared.tsx`,
  `src/app/docs/layout.tsx`, `src/app/docs/[[...slug]]/page.tsx`, `src/components/mdx.tsx`,
  `src/components/mdx/mermaid.tsx`, plus any new `src/components/**` and font assets. **Do not** touch
  `scripts/`, `content/docs/`, or the notes pipeline.

---

**Deliverables**

1. Updated theme tokens and global styles (light + dark).
2. Restyled nav/brand, sidebar, landing cards + hero, doc body (tables, blockquotes, inline-code
   chips, callouts).
3. Themed Mermaid + KaTeX.
4. `next/font` wiring for heading, body, and Devanagari fonts.
5. A brief summary of what changed and how to tweak the palette (which CSS variables to edit).

**Acceptance criteria:** `npm run dev` and `npm run build` succeed; `npm run lint` is clean; search,
sidebar ordering, theme toggle, Mermaid, KaTeX, and Sanskrit rendering all work in light and dark;
no edits to generated `content/docs/` or the sync script.
